# Evaluator の回の決まり（dotfiles）

自動開発の起動スクリプトは、このファイルがあるリポジトリで、週に1回 Evaluator の回を動かす。手順の本体は evaluator スキル（`claude/skills/evaluator/SKILL.md`）にあり、ここにはこのリポジトリに固有のことだけを書く。

## 評価の対象

- 自動開発に登録されているすべてのリポジトリの Bot（材料の `repos/` にあるリポジトリの、自動開発の回と PR の自動レビュー）。
- このリポジトリの `claude/skills/` のスキル。

## 書く場所

- このリポジトリは公開なので、評価を Issue や PR に書かない。評価には、ほかのリポジトリの名前や、Issue・PR・会話の中身が入るため。記録は Notion の開発ログに書く。
