# 全般
- 応答は常に日本語で行う。
- `rm -rf /` など、システム全体を破壊しうるコマンドは絶対に実行しない。

# Git コミットメッセージ
作業内容を表す接頭辞を付け、その後に日本語で1行にまとめる。例: `[fix] ログイン時のセッション切れを修正`
- Claude Code がコミットするときは、先頭に `🤖` と半角スペースを付ける。例: `🤖 [fix] ログイン時のセッション切れを修正`
- `Co-Authored-By` などの署名行は付けない。

| 接頭辞 | 用途 |
|---|---|
| `[add]` | 新機能や新ファイルを追加 |
| `[update]` | 既存機能の改善や更新 |
| `[fix]` | バグ修正 |
| `[refactor]` | リファクタリング |
| `[remove]` | ファイルや機能の削除 |
| `[style]` | コードスタイルの修正 |
| `[docs]` | ドキュメントの更新 |
| `[test]` | テスト関連の変更 |

# 言語ごとの標準コマンド（プロジェクト側に指定がなければこれを使う）
- Go: フォーマット `gofmt -w .` / Lint `golangci-lint run` / テスト `go test ./...`
- PHP: フォーマット `composer run phpcbf` / Lint `composer run phpcs` / テスト `composer test`
